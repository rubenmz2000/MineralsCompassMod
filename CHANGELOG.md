# Materials Compass — Changelog

## [0.0.1] — 2025-11-09
### Added
- First release of the **Materials Compass** mod.
- Added item **Materials Compass**, available in creative mode.
- Experimental tooltip indicating the object status.
- Compatibility with **Minecraft 1.20.1** and **Forge 47.4.10**.

### Known Issues
- The object is **not yet obtainable in survival mode**.
- Some functionalities are **placeholders** for internal testing
