# Materials Compass
A minecraft mod that adds a configurable compass capable of detecting different minerals.

## Version
- **0.0.1** (Compatible with Minecraft 1.20.1 / Forge 47.4.10)
## Installation
1. Install **Minecraft Forge 1.20.1**.
2. Place `materials-compass-x.x.x.jar` into your `mods` folder.
3. Launch Minecraft and enjoy!.
